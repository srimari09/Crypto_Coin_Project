#CryptoCoin

A cryptocurrency tracking application developed using Flutter and Dart, with a Node.js backend.

#Features

Cryptocurrency listing

Search cryptocurrencies

Multiple currency support

FAQ details

Coin details

Price history charts

Market statistics

Watchlist

#Technologies Used

Frontend: Flutter, Dart, Provider, Dio, fl_chart

Backend: Node.js, Express.js, Axios

API: CoinGecko API

#Project Structure

crypto_coin – Flutter application

crypto_backend – Node.js backend
